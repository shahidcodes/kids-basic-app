# Kids Learn (web)

The web version of Kids Learn, live at **[kidyapp.vercel.app](https://kidyapp.vercel.app)**.

- **Say Mode**: press a letter or number and hear it spoken
- **Correct Mode**: find the letter shown, against a timer, with points and streaks
- **Write Mode**: trace letters on a canvas
- **Melody Mode**: each key plays a note and speaks its letter
- English, Arabic and Dhivehi, with Easy, Medium and Hard difficulty levels
- Speech uses the browser's Web Speech API, so available voices depend on the device

Built with Next.js, React and Tailwind CSS.

## Running locally

```bash
npm install
npm run dev
```
